# 安装 DSH Remote

需要 Android 8.0 或更高版本。安装包在 [GitHub Releases](https://github.com/Loki-0228/dsh-remote-link/releases/latest) 的 `DSH-Remote.apk` 附件，采用开发签名，供直接安装。保留 `.signing/debug.keystore`，以便后续构建能够覆盖安装。

1. 在电脑退出旧启动器，重新打开本目录新版 `DSH-Web.exe`。exe 同目录必须保留 `native-notifications` 文件夹。
2. 将 APK 传到手机并安装，按 Android 提示允许该来源安装应用。
3. 电脑上的「远程链接」生成配对链接。外网访问时先开启隧道。
4. 在 APK 粘贴完整链接，点击「配对并接收通知」。也可从手机浏览器分享链接给 DSH Remote。
5. 允许通知权限，等待通知栏显示连接状态。

任务开始、结束、出错、待审批和提问会显示系统通知。点击审批提醒，查看操作内容后选择「允许本次」或「拒绝」。提问通过应用内的官方会话界面回答。电脑撤销设备后应用停止接收，需重新配对。

应用用 Android 前台服务维持长轮询，没有接入 FCM 或第三方推送服务。电脑须保持运行且网络可达。手机省电限制、深度休眠或强行停止应用可能阻止接收；可在系统电池设置中允许后台运行。手机重启或强行停止后，打开应用并点击「继续接收通知」。

HTTP 明文传输设备凭据与内容，连接前会显示确认提示；外网建议配置 HTTPS。设备凭据用 Android Keystore 加密，应用不允许系统备份。

## 构建

```powershell
pwsh -File apps/android/build.ps1 -Sdk D:/SDK -Java D:/Java/jdk-17
```

在仓库根目录执行命令，产物输出到 `release/DSH-Remote.apk`。需要 SDK Platform 35、Build Tools 35.0.1、JDK 17。脚本直接调用 SDK 完成 Java、DEX、资源编译、APK 对齐和签名校验，无需 Gradle。
## 通知设置

打开首页的「通知设置」，分别开启或关闭任务开始、任务结束、任务失败、操作审批、需要回答的问题、其他插件消息。设置立即保存，只影响当前手机，重新配对后仍保留。关闭某类提醒会移除该类已经显示的通知，不会拒绝审批或删除待处理请求。

「简略通知」默认开启，显示任务名称和本轮回答的文字摘要。例如「本轮结束 · 导出季度报表」，正文为「报表已导出，共 120 行」。关闭后，展开通知可阅读较长内容；点击通知可查看详情并打开远程会话。电脑端必须同步更新 native-notifications 目录并重启，才能提供新摘要。

声音、振动、勿扰和通知权限由 Android 系统设置管理，APK 不提供独立音效或试听功能。后台连接通知随接收服务启停。

远程会话支持横竖屏切换。旋转时保留原 WebView、页面状态和未发送的输入内容。系统回收应用进程后会尝试恢复远程页面，但网页未保存的草稿不保证恢复。

## 回归验证

纯文字展示测试位于 tests/NotificationTextTest.java。设备测试仅允许临时 Android 模拟器，会覆盖该模拟器内的配对和通知设置。

先运行 tests/fixture-server.mjs，再执行 tests/test-device.ps1。测试覆盖真实通知投递、按类型过滤、锁屏隐私、设置持久化，以及测试网页在横竖屏切换后的显示与草稿保留。截图保存在模拟器应用的外部 files 目录。测试不向真实 DeepSeek 会话发送消息。
